# 野草分布図アプリ（iPad用） Ver 3.1

樹木位置図を背景に、野草50種の分布を Apple Pencil で描き、面積の集計と図面画像の出力を行うWebアプリです。GitHub Pages で公開し、iPad の Safari で「ホーム画面に追加」して使います。

## ファイル（すべてリポジトリの直下に置きます）

| ファイル | 内容 |
|---|---|
| index.html | アプリ本体 |
| base.png | 背景図面（250702_樹木位置、樹木の凡例を除去、A4・1/225） |
| seed.json | 2024・2025年の分布データ（250508野草分布.dxf から変換、50種） |
| sw.js / manifest.json | オフライン動作・ホーム画面追加・更新の通知 |
| icon-180.png / icon-512.png | アイコン |

## iPhone から GitHub に公開・更新する

1. Safari で github.com を開き、リポジトリの「Add file」→「Upload files」。
2. 「ファイル」アプリから上の7ファイルを選んで「Commit changes」（既存ファイルは上書きされます）。
3. 初回のみ：「Settings」→「Pages」→ Branch「main」「/(root)」→「Save」。
4. 数分後、iPad でアプリを開くとスタート画面に「新しいバージョンがあります」が出るので「更新する」を押します。

次に更新するときは、sw.js の `VERSION` と index.html の `APP_VERSION`・`APP_DATE`・`CHANGES` を書き換えてからアップロードしてください。

## 主な機能

- **スタート画面**：バージョンと更新の有無、種数・年度・最終保存日、「はじめる（続きから）」「一覧・面積」「出力」「設定」「使い方」
- **編集中の表示**：地図の上に「年度・番号・種名・面積・前年比」を常に表示。「‹ ›」で種を切り替え、種名をタップで一覧から選択
- **道具**：囲って塗る／多角形／ブラシ（太さ 0.3〜3m＋スライダー）／点（直径 0.2〜1m）／囲って消す／消しゴム／前年から写す／選んで直す／戻す・やり直す
- **多角形**：タップした所に点を置いてつなぐ。最初の点をタップで閉じる。「1点戻す」「塗る／消す」の切り替えあり
- **前年から写す**：前年の範囲をタップで1つ、なぞって囲むとまとめてコピー。「すべて写す」もあり
- **選んで直す**：範囲を選ぶと頂点が丸印で表示され、ドラッグで移動、線をタップで点を追加、「選んだ点を削除」で削除。内側をドラッグで全体を移動（頂点の編集は囲って塗る・多角形・DXF取り込みの範囲が対象）
- **色**：年度ごとの色（2024年 赤、2025年 オレンジ、2026年 紫が初期値）と塗りの濃さをツールバーから変更
- **前年の重ね表示**：斜線または下絵（塗り）で任意の年度を重ねる。「写して描き始める」で前年の分布をコピーして修正
- **確認済み**：調査で確認した種に印を付け、種の一覧で「未記入／記入済み／確認済み」を絞り込み
- **出力**：凡例は「左下（図面の下に凡例欄：年度・種名・面積）」か「右下（過去図面と同じ位置）」を選択。1種ずつPNG、全種ZIP、面積CSV
- **種の管理**：追加・名前の変更・並べ替え・削除（設定、または種の一覧の「＋ 種を追加」）

凡例は出力画像にだけ描き込むので、分布データにも面積にも含まれません。

## データの保存

描いたデータは iPad の中に自動保存されます。Safari のサイトデータを消すと失われるため、設定 →「バックアップを保存」で定期的に保存してください。

## 面積の計算

描いた範囲を約2.3cm四方の画素に分けて数えています（重なりは1回だけ数え、消した部分は除外）。2024・2025年データでは CAD 上の面積との差は合計で0.05%程度です。
