# 野草分布図アプリ（iPad用）

樹木位置図を背景に、野草54種の分布範囲を Apple Pencil で描き、面積の計算と図面画像の出力を行うWebアプリです。GitHub Pages で公開し、iPad の Safari から「ホーム画面に追加」して使います。

## ファイル

| ファイル | 内容 |
|---|---|
| index.html | アプリ本体 |
| base.png | 背景図面（250702_樹木位置.pdf を画像化、樹木の凡例を除去、縮尺 1/225） |
| seed.json | 2024・2025年の分布データ（250508野草分布.dxf から変換） |
| manifest.json / sw.js | ホーム画面追加・オフライン動作用 |
| icon-180.png / icon-512.png | アイコン |

## iPhone から GitHub に公開する手順

1. Safari で github.com にログインし、右上「＋」→「New repository」。名前（例：yasou-bunpu）を入れ、Public を選んで作成。
2. リポジトリ画面で「Add file」→「Upload files」→「choose your files」。「ファイル」アプリから README.md 以外の7ファイル（README.md も入れて構いません）をまとめて選び、「Commit changes」。
3. 「Settings」→「Pages」→ Branch を「main」「/(root)」にして「Save」。
4. 数分後に `https://ユーザー名.github.io/yasou-bunpu/` で開けます。
5. iPad の Safari でそのURLを開き、共有ボタン →「ホーム画面に追加」。

アプリを更新するときは、ファイルを上書きアップロードし、sw.js の `VERSION` を `v3` などに変えてください。

## 使い方

- **Apple Pencil で描く／指で移動・拡大**（設定で「指でも描く」に切り替え可）
- **囲う**：なぞった範囲を塗りつぶし　**囲って消す**：なぞった範囲を消去
- **ブラシ／消しゴム**：太さは画面下のスライダー（m単位）
- **前年表示**：前年度の分布を斜線で重ねて表示
- **一覧**：全種の面積・前年比。行をタップでその種へ移動
- **出力**：表示中の種のPNG、全種PNG＋面積CSVのZIP、全年度の面積CSV
- **設定**：年度の追加、種名（50行まとめて貼り付け可）と色、縮尺、背景図面の差し替え、バックアップ

## データの保存について

描いたデータは iPad の中（Safari のサイトデータ）に自動保存されます。Safari の履歴・サイトデータを消すと消えるため、**設定 →「バックアップを保存」で定期的にJSONを保存**してください。別のiPadへの移行も、このJSONの読み込みで行えます。

## 2024・2025年データ

250508野草分布.dxf の内容は seed.json としてアプリに入っており、初回起動時に自動で読み込まれます。

- レイヤ「野草○○2025」→ 2025年（オレンジ）
- レイヤ「野草○○」（年なし、凡例は「2023年・2024年」など）→ 2024年として登録（赤）。凡例の年表記は元の図面の文字をそのまま使います
- レイヤ「野草○○2024」→ 2024年
- 右下の凡例用の図形は除外し、ハッチ（塗りつぶし）を分布として取り込んでいます

設定 →「2024・2025年の初期データを読み込み直す」で、いつでもこの状態に戻せます。

## 出力の体裁

過去の図面と同じく、背景図面（A4・1/225）の右下に「凡例」「●：種名（年）」を入れて出力します。分布は年度の色で50%の透明度で塗り、輪郭線を付けます。年度の色は 設定 → 年度 の色見本で変更できます（2024年は赤、2025年はオレンジ、2026年は紫が初期値）。

## DXF の取り込み（追加のデータがあるとき）

設定 →「DXFから取り込む」でファイルを選びます。250508野草分布.dxf と同じ座標の図面なら位置合わせは自動です。違う図面の場合は「2点を指定して合わせる」を選び、AutoCAD の ID コマンドで調べた2点の座標を入力して図面上でタップします。

取り込めるのは閉じたポリライン、ハッチ、円、楕円、閉じたスプラインです（初期設定ではハッチのみ）。

## 面積の計算

描いた範囲を約2.3cm四方の画素に分けて数えています（重なりは1回だけ数え、消した部分は除外）。2024・2025年データで CAD 上の面積と比べた誤差は合計で0.05%程度です（直径30cmの点1つ程度の小さな分布では数%ずれます）。縮尺は図面の通り芯間隔から設定済みで、設定から2点の距離で調整できます。
