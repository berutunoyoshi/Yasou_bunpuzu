# 野草分布図アプリ（iPad用）

樹木位置図を背景に、野草50種の分布範囲を Apple Pencil で描き、面積の計算と図面画像の出力を行うWebアプリです。GitHub Pages で公開し、iPad の Safari から「ホーム画面に追加」して使います。

## ファイル

| ファイル | 内容 |
|---|---|
| index.html | アプリ本体 |
| base.png | 背景図面（250702_樹木位置.pdf を画像化、縮尺 1/225） |
| manifest.json / sw.js | ホーム画面追加・オフライン動作用 |
| icon-180.png / icon-512.png | アイコン |

## iPhone から GitHub に公開する手順

1. Safari で github.com にログインし、右上「＋」→「New repository」。名前（例：yasou-bunpu）を入れ、Public を選んで作成。
2. リポジトリ画面で「Add file」→「Upload files」→「choose your files」。「ファイル」アプリから上の6ファイルをまとめて選び、「Commit changes」。
3. 「Settings」→「Pages」→ Branch を「main」「/(root)」にして「Save」。
4. 数分後に `https://ユーザー名.github.io/yasou-bunpu/` で開けます。
5. iPad の Safari でそのURLを開き、共有ボタン →「ホーム画面に追加」。

アプリを更新するときは、ファイルを上書きアップロードし、sw.js の `VERSION` を `v2` などに変えてください。

## 使い方

- **Apple Pencil で描く／指で移動・拡大**（設定で「指でも描く」に切り替え可）
- **囲う**：なぞった範囲を塗りつぶし　**囲って消す**：なぞった範囲を消去
- **ブラシ／消しゴム**：太さは画面下のスライダー（m単位）
- **前年表示**：前年度の分布を斜線で重ねて表示
- **一覧**：全種の面積・前年比。行をタップでその種へ移動
- **出力**：表示中の種のPNG、全種PNG＋面積CSVのZIP、全年度の面積CSV
- **設定**：年度の追加、種名（50行まとめて貼り付け可）と色、縮尺、背景図面の差し替え、バックアップ

## データの保存について

描いたデータは iPad の中（Safari のサイトデータ）に自動保存されます。Safari の履歴・サイトデータを消すと消えるため、**設定 →「バックアップを保存」で定期的にJSONを保存**してください。別のiPadへの移行も、このJSONの読み込みで行えます。

## 2024・2025年データ（DXF）の取り込み

1. AutoCAD で 250508野草分布.dwg を開き、「名前を付けて保存」→ ファイルの種類「AutoCAD 2018 DXF」で保存。分布がブロックになっている場合は先に分解（EXPLODE）。
2. AutoCAD の ID コマンドで、通り芯の交点など2点の座標を控える。
3. アプリの 設定 →「DXFから取り込む」でファイルを選び、2点の座標を入力して図面上でその位置をタップ。
4. レイヤごとに種と年度を選び（レイヤ名に種名・年が入っていれば自動選択）、「位置を図面で確認」→「取り込む」。

取り込めるのは閉じたポリライン、ハッチ、円、楕円、閉じたスプラインです。

## 面積の計算

描いた範囲を約2.3cm四方の画素に分けて数えています（重なりは1回だけ数え、消した部分は除外）。縮尺は図面の通り芯間隔6,000mmから設定済みで、設定から2点の距離で調整できます。
